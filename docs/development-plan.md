# ABank 功能完善开发计划与会话交接

更新日期：2026-10-16。分析基线：`1d52c4e`。本文是后续会话的统一开发入口，实际源码和 Git 状态优先于文档快照。

## 1. 文档定位与接手方式

目标：基于农行真实截图和已有资源，逐步补齐页面、交互及本地数据联动，优先解决入口存在但点击只有提示的问题。

### 项目约束

- UIKit + SnapKit、Swift 5、iOS 15.6+；打开 `ABank.xcworkspace`。
- 银行业务全部使用本地模拟数据，不接入银行接口、服务端或真实认证。
- 资讯保留已完成的公开 RSS、缓存、搜索和阅读能力。
- 有真实截图的页面按截图还原；缺少截图的页面沿用现有视觉规范，并记录待核对项。
- 默认每次会话完成一个阶段或一个可独立验收的子任务；用户未要求时不提交、不推送代码。

### 接手步骤

1. 阅读 `CLAUDE.md`、本文及 [功能缺口分析](abc-feature-gap-review.md)。
2. 检查 `git status`、近期提交和实际源码，确认文档是否落后；保留已有未提交修改。
3. 选择首个未完成任务，检查依赖和已有实现，避免重复开发。
4. 实现后完成数据检查、构建及模拟器验收，再更新本文交接记录。

已有五个主 Tab、账户首页、账户明细查询、借记卡详情；资产负债、收支筛选及交易分类/备注/账本编辑；贷款合同、应还详情、提前还款页面和使用记录；客户资料、手机号与税收身份表单；动态资讯及缓存降级。

## 4. 实现约定与验收

### 数据与接口

- 根账本增加兼容解码的转账记录，旧数据缺少字段默认为空，不清空已有编辑。
- 新增 `TransferDraft`、`TransferRecord`、`TransferStatus`，记录付款账户、收款人、金额、时间、状态和关联交易 ID。
- 统一 `submitTransfer(draft:requestID:)`，同一请求 ID 重复提交返回已有结果。
- 转账记录和流水同一次根记录保存；余额不足、超限、取消和失败不生成扣款，编码失败不得返回成功。
- 新转账用整数分计算，与现有 Double 字段集中转换；本轮不全面迁移历史金额模型。
- 功能目录使用稳定 ID 和类型化路由，不依赖显示文案判断路由。
- 安全设置、网点、权益订单分别由本地 Store 管理，跨模块共用状态。
- 财富扩展增加持仓及统一资产汇总；现金扣减与持仓新增同时成功。

### 资源与视觉

- 优先已有语义资源；新映射同步更新导入脚本和来源清单。
- 按 `abc_<module>_<purpose>` 命名，保留尺度、透明度及 original/template 渲染。
- 不重复导入整包，不提交下载包或临时验证文件。
- 核对字体、字号、颜色、行高、间距、图标比例、圆角、导航栏及各种状态。
- 缺少截图的页面记为“按现有规范设计”，取得截图后再校准，不宣称逐像素还原。

### 必测场景

- 转账：金额边界、余额不足、超限、重复提交、取消、失败重试及重启恢复。
- 联动：余额、明细、收支、资产、订单与回单对同一交易一致。
- 账单：跨月/空月、分类调整、不计入收支、退款及筛选。
- 网点/权益/订单：重复操作、取消、过期、空态及返回刷新。
- 兼容：已有账本与用户编辑保留，新增字段缺失可正常读取。
- UI：长标题、大金额、小屏幕、滚动、键盘遮挡、金额隐藏及多入口返回。

关键数据规则用独立 Swift 检查，参照 `scripts/check_news_data.swift`；简单样式不加机械测试。

每阶段构建：

```sh
xcodebuild -workspace ABank.xcworkspace -scheme ABank \
  -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /private/tmp/ABank-ResourceBuild \
  CODE_SIGNING_ALLOWED=NO build
```

模拟器先查询当前设备，不复用历史 ID。截图验证和完整点击回归分别记录；交付前移除临时 QA 入口。
