# 环境与资产恢复

## 已发现的项目入口与锁文件

- `README.md`

## 恢复顺序

1. 先查看隔离恢复报告，核对 Git 状态与缺失文件，不覆盖当前工作目录。
2. 按上述 README、项目完整规范及锁文件安装相应版本；不自动升级依赖。
3. 缓存安装和构建命令以项目现有文档为准；本轮未执行此项目业务构建。
4. 按 exclusions.json 重新配置凭据、Git remotes、MCP 和外部服务；凭据不写入交接文档。

## 必须保留的资产与待验收事项

- iOS 签名身份、钥匙串和 provisioning 需重新配置；本轮未进行设备、签名、上传或 App Store 验证。
- 有 workspace 时沿用项目 workspace；不要只打开 xcodeproj 代替依赖配置。
- 工具和素材的绝对路径映射保存在私有快照清单，不写入共享仓库。
- 全局技能的外部链接目标另存于 native/ 下，需在新机检查映射；不直接启用原账号插件或任务队列。
- 参考本机 registry/histories 核对原生会话编号；找不到旧聊天时通过 tasks/ 记录继续。
