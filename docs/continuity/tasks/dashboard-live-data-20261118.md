# 首页与「我的」数据联动

基线为 `main@3ba041e`，开始时工作树干净。会话 `01a1f1b8-82ab-7a03-9c3b-8732d5f6e25e`。

- 「我的」按北京时间同时更新本月收支和上月账单，账单只统计已计入收支的流水。11 月显示「11月收支」，若 10 月有统计数据则提示「您的10月份账单已出」，否则显示该月暂无记录。卡片、消息通知及详情跳转共用账单月份。账单未读状态复用原有消息记录。
- 财务卡继续读取本地账本，用户资料及登录时间在刷新时读取对应 Store，删除构造页面时保存的重复快照。
- 首页「日常权益」取签到、可用积分、卡券数据，卡片可跳转对应页面。通过页面出现、前台切换、北京时间跨日及既有数据通知刷新。
- Debug 模拟器构建、17 组数据回归和 `git diff --check` 通过。账单回归覆盖北京时间月界、跨年文案、空月、排除统计的流水、补录后发出消息及保存已读状态。独立 iPhone SE 3 和 iPad Pro 11 英寸通过 XCUITest，验证 11 月收支、10 月账单直达，以及首页签到卡在签到后更新。未验证真机。
- 财富页续作见 [财富页数据来源统一](wealth-live-data-20261118.md)。两项改动纳入同一提交，目标分支为 `ABank/main`。
