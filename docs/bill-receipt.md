# M2：月度账单、收支分析、交易搜索与电子回单

## 当前能力与边界

- **月度账单 / 收支分析**：`MonthlyBillViewController` 同一页面两种入口。「我的」资产负债卡和本月收支卡的账单入口打开上月账单；收支页「分析」按当前月份（自定义区间取结束月）和当前账户筛选打开“收支分析”。页面包含月份切换、支出/收入/结余汇总、支出或收入分类占比、主要收支前三笔、近 6 个月趋势柱状图（点击切换月份）及页面内金额隐藏。
- **交易搜索**：收支页搜索按钮进入 `TransactionSearchViewController`，在全部月份中搜索交易对方户名/账号、摘要、附言、备注、分类、账本、交易类型、渠道和金额，结果按完整日期分组，点开进入现有收支详情。
- **电子回单**：仅从本机成功且已入账的模拟转账派生。入口：转账结果页、转账记录页右上角、收支详情右上角（仅转账流水）、账户明细查询“回单查询”（限定该账户）、收支页“更多”。回单详情可通过系统分享面板分享图片及文字。
- 账单与回单缺少原版页面截图，布局按项目现有白色卡片和青绿色样式设计，取得截图后再校准；不宣称还原原版。

## 统计口径

- 全部由 `FinanceLedgerStore` 同一账本只读派生，不写入、不更新数据时间戳；收支详情中修改“计入收支”或分类后，返回账单即按新值统计。
- 只统计 `includeInFlow == true` 的交易；不计入收支的笔数单独显示，不参与金额。按方向统计，不额外识别退款：退款按收入方向的流水计入。
- 金额先由 `TransferMoney.cents(from:)` 转为整数分再合计，避免 Double 累加误差；与「我的」月收支、收支页汇总按分比较一致。
- 账户范围沿用收支页的 `IncomeExpenseAccountFilter`（全部 / 不含手工记账 / 借记卡 / 手工记账），判断逻辑集中到 `IncomeExpenseAccountFilter.matches(_:)`。
- 分类按金额降序；主要收支按金额降序、同额较新者在前，取前三。趋势为截至所选月的近 6 个月。可切换月份为最早流水月份（至少回看 12 个月）到当前月。
- 从账单分类进入的收支列表带上月份、账户和该分类筛选；高级筛选按分类过滤、不区分方向，“本人资金往来”分类会同时显示收入与支出。

## 收支分组修正

`IncomeExpenseDayGroup` 改为按完整日期 `yyyy-MM-dd` 分组。跨月自定义区间不再把不同月份的同一日合并，分组跨月时标题显示“M月d日”；单月仍显示“d日”。

## 电子回单

- `TransferReceipt` 不单独持久化，由 `TransferRecord`、关联流水和付款账户派生；失败记录、缺少 `transactionID` 或关联流水不存在时不生成回单。同一请求 ID 的重复提交不会产生第二张回单。
- 回单编号稳定：`SIM` + 交易时间数字 + 记录 ID 末 6 位，重启后不变。
- 只展示脱敏的付款卡尾号和收款账号/手机号；分享文字同样不含完整卡号。
- 卡片顶部标注“模拟交易 · 非真实凭证”，全卡斜向浅色“模拟交易”水印，底部免责声明；不使用银行印章或签章图形。金额同时给出人民币大写（`RMBUppercase`）。
- 分享使用 `UIActivityViewController`；为支持“存储图像”，工程增加 `NSPhotoLibraryAddUsageDescription`。
