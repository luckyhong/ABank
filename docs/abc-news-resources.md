# 资讯页资源更新

目录 `ABank/Assets.xcassets/ABCImported/News/`。统一前缀 `abc_news_`，Menu / Toolbar / Decorations 按导入脚本分类，其中本页无业务 Menu。共 23 个 imageset、46 张 2x/3x PNG。原始路径、SHA-256 和尺寸见 `abc-news-resource-manifest.json`，仅更新本页目录的脚本为 `scripts/import_news_assets.py`。

接入：

- 顶部扫一扫、客服、消息、搜索、麦克风；单色轮廓按页面 tint 显示。
- 7×24 快讯、热门视频、资讯热榜、互动话题原版标题图。
- 排行 1/2/3 数字及热/新标签保留原始颜色；小标签保留文字布局与可访问文本。
- 分类编辑图标、推荐/关注话题中的热度图标。
- 轮播以包内通用财经配图替换系统图形和人工金币，增加暗色遮罩保障标题可读性；该图为原版回退/配图，不是本地假新闻对应的真实报道照片。
- 文章缩略图及热门/列表视频封面使用原版中性占位图。缩略图和封面铺满图片区域，不将完整占位背景缩成小符号。
- 列表视频标签使用原版图。专题标签、方形照片及竖向视频占位资源保留于该分组作为后续接入素材，没有把无对应内容的真实宣传视频海报接入假新闻。

共用 SectionHeaderView 增加可选 imageName，未提供时保持现有文字标题，首页/生活等既有用法不受影响。榜单及标签通过 NewsResourceArtwork 叠加图片，同时保留 label 的布局与可访问文本。

页面数据、加载更多、推荐/关注切换及互动题流程继续使用本地假数据，未引入接口。关注账号头像、未匹配专题横幅和文章内容保留现有本地表达；没有当前线上封面就不宣称图像与新闻正文对应。此结果还原包内静态视觉素材，不等同于当前真实 App 的全部线上布局。

验证：常规模拟器构建、图片解码、语义名称与文件引用检查；iPhone 16 Pro / iOS 18.3 首屏截图观察快讯、热门视频、排行和标签。关注页、分类编辑、互动点击尚未进行运行交互验证。渲染截图期间临时选中资讯 Tab，最终恢复默认首页。截图保存于本地 artifacts/abc-resources/verification/news-top.png。
