# M2：账单分析、交易搜索与模拟回单

全部数据派生自现有 `FinanceLedgerStore`，不修改 v8 存储结构，不补造流水、不重新提交转账。安全设置限额编辑仍留到 M4。

## 入口与口径

- 我的两个月度账单入口默认查看上月；收支“分析”保留当前日期、账户及高级筛选。可复用日期面板切换月份/自定义范围。
- 汇总、分类金额/占比、主要收支前10笔仅统计 `includeInFlow`，收入与支出独立计算分类比例；退款按账本中的收入方向统计，不推断或抵销原消费。
- 月份模式显示截至所选月的6个月收支趋势（含空月0值），保留账户和高级筛选。自定义范围显示整个范围汇总，不伪装成某一个月。
- 搜索沿用进入时的范围、账户、金额与分类筛选，支持名称、对方、脱敏账号、摘要、附言、备注、分类、日期、金额与账户标签。空关键词显示范围内全部记录，空格分词须全部匹配；不计入收支的记录仍可搜索。详情编辑后返回自动刷新。
- 收支仍按日分组，键改为完整 `yyyy-MM-dd`，日期降序；标题显示完整日期，跨月/跨年同一日不会合并。

## 回单

转账记录右上角、成功结果页和账户明细“回单查询”接入回单。账户入口保留账户限制。仅现有成功 `TransferRecord` 且 `transactionID` 能关联现有流水时可显示；失败、无关联流水及旧种子交易不生成回单。

回单记录原始确认金额、时间、付款标签、收款姓名/银行/脱敏标识和附言，展示完整模拟单号及关联流水 ID。流水分类、备注等编辑不改写原始转账信息。

详情和导出均标注“模拟交易”“非银行凭证”，无银行印章。系统分享面板分享 UTF-8 `.txt` 文件，支持系统“存储到文件”等操作；文件名同样含模拟交易。分享前重新读取已存在记录，不调用提交/扣款 API，完成或取消分享后清理临时文件。

页面沿用现有 UIKit、青绿色和卡片规范，复用日期面板；没有新增资源，也没有原版子页截图依据。趋势当前以逐月金额列表呈现，待真实截图后校准视觉。

## 验证

运行 `scripts/check_banking_data.sh`，分别执行 M0/M1/M2 隔离 UserDefaults 检查。M2 检查覆盖跨月跨年完整日期分组、空月、分类比例、退款收入、不计入收支、账户过滤、多关键词、备注编辑刷新、关联回单、脱敏、重复读取不写账本、失去关联时不可用。

正常版本构建及模拟器验收结果见开发计划最新交接记录。数据脚本不读写正常 App 账本。
