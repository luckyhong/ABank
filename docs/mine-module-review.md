# 我的模块梳理与分阶段资源更新

## 结构与入口

当前 Mine 目录有 15 个 ViewController，分为首页、客户信息、资产负债、收支和贷款五条页面链。下列结论来自源代码中的实际导航，不把提示按钮视为已经实现的业务页。

| 入口 | 实际页面链 | 主要来源 |
| --- | --- | --- |
| 首页头像 | 客户信息 → 修改手机号 / 税收身份 | ABank/Features/Mine/MineViewController.swift、CustomerInfo/CustomerInfoViewController.swift |
| 资产负债卡 | 资产负债 → 活期账户的收支记录 / 我的贷款 | AssetLiability/AssetLiabilityViewController.swift 的 navigate |
| 本月收支卡 | 收支首页 → 详情 / 筛选；日期、账户选择 sheet | IncomeExpense/IncomeExpenseViewController.swift |
| 我的贷款 | 本月待还 / 合同详情；合同详情 → 提前还款 / 用款记录 / 还款详情；还款详情 → 筛选 | MyLoan/MyLoanViewController.swift、LoanDetailViewController.swift、LoanRepaymentDetailViewController.swift |
| 权益、星级、网点、安全、订单及顶部操作 | 当前部分入口仅 showToast | MineViewController.swift 的 bindActions |

首页的银行卡、小豆、积分、礼券当前是统计展示，不存在独立跳转绑定。网点首页图标入口继续展示提示；此次没有将素材接入扩展成真实银行业务。

共享本地状态：CustomerInfoStore 管理客户资料，返回首页时刷新脱敏姓名；FinanceLedgerStore 提供首页资产/收支、资产负债分类和贷款数据。客户资料与财务数据不是互不关联的展示副本，后续改子页必须保留这些回填和联动。

## 第一阶段：我的首页

本次资源位于 `ABank/Assets.xcassets/ABCImported/Mine/`，统一前缀 `abc_mine_`，共 21 个 imageset、29 张 PNG。`abc-mine-resource-manifest.json` 记录原始文件、哈希、尺寸和尺度；`scripts/import_mine_assets.py` 仅更新该资源分组。

接入顶部退出/搜索/设置/更多、通用头像占位、星级徽标、权益按钮、统计卡纹理、财务标题背景、睁眼/闭眼、网点刷新及四个服务入口、四个安全入口、客户经理企业微信。按钮单色轮廓使用 template rendering；彩色图标和背景保留 original rendering。金额显隐沿用原逻辑，两个眼睛状态都接入，未只替换初始状态。

参考官方商店 `appstore-public/screenshot-05.jpg` 的黑金统计卡、金色权益与浅金财务区域；素材从 11.3.0 包提取。商店截图可能较旧，不代表当前原 App 的登录身份、具体金额或远程运营内容。头像使用原版通用占位，不使用真实客户照片；客户经理姓名仍为 Mock，没有拿其他人物照片冒充客户经理。

本次保留项目现有资产负债账单行、收支比例条与下方卡片排列；未以旧商店截图删除已存在的本地功能。普通返回箭头和订单纯文字行继续用通用控件。

## 后续优先顺序

1. 客户信息：头像/证件拍摄、表单右侧箭头、职业/地区 picker、修改手机号与税收身份。重点检查文字长度、滚动到底部、保存返回后的姓名刷新。
2. 资产负债：摘要、分类与子项、空分类、金额显隐、活期账户/贷款入口。保持 FinanceLedgerStore 的数值一致性。
3. 收支：筛选条、摘要、交易图标、账户/日期/收入支出筛选 sheet 和详情。检查单行/多行标题行高与自适应弹层。
4. 贷款：摘要、合同展开、待还清单、还款详情与筛选、提前还款和用款记录。分别检查金额隐藏、合同切换、日期区间和空列表。
5. 当前仅提示的安全、订单、网点等入口：需要先明确练习页范围，不能把资源素材存在等同于页面已实现。

上述为待办，子页面尚未完成资源更新，不能描述整个 Mine 已还原。每轮应先核对原图语义，再完成所在页面截图、构建和必要的状态回归。

## 验证记录

首屏及下半页使用 iPhone 16 Pro / iOS 18.3 模拟器截图，观察统计/财务卡片、网点/安全图标和客户经理区域。金额隐藏通过临时设置两个卡片为隐藏状态进行渲染验证；此次没有运行手指点击眼睛及全部子页返回流程。模拟器截图期间临时选中 Mine 和滚动定位，所有验证入口代码最终恢复。

本地截图保存于 artifacts/abc-resources/verification/mine-top.png 和 mine-lower.png。常规模拟器构建、资源名称/文件引用检查通过。资讯列表间距修复仍作为前序未提交修改保留。

## 首页素材适配修正

依据红框截图：权益按钮取消包含箭头和阴影的素材九宫格拉伸，缩小文字以保留箭头空间；统计卡在渲染时裁掉原始 1125px 素材左右各 60px 的透明边，移除深灰底色，保留原图白色弧线；统计文字上移 10pt，避免标签落在白色弧线区域。财务标题背景由标题内部移到卡片顶部，全宽显示并只裁切顶部圆角，文字/眼睛/箭头继续保留原内边距。原始资源文件未覆盖。

修正后的模拟器截图：artifacts/abc-resources/verification/mine-layout-fixed.png。

权益按钮进一步调整：原背景内嵌的长金色光晕不适合当前紧凑入口，现改为原生横向金色渐变、6pt 圆角和独立尾部箭头。按钮视觉高度 28pt，文字/箭头由 UIButton.Configuration 居中排布；原始背景资源保留但该按钮不再引用。该样式是基于原版金色视觉语言的适配，不是原背景逐像素复制。渲染验证截图：artifacts/abc-resources/verification/benefits-fixed.png。

## 按用户提供的当前真实页面参考调整

此次以用户提供的完整真实页面截图为准，覆盖此前旧商店截图带来的浅金标题背景判断：首页顶部改白底，财务卡恢复纯白标题；权益入口采用白字金底和轻微阴影，文字单行，箭头独立排版。星级徽标移至头像下方独立行，取消金色胶囊底；采用包内与参考一致的通用男生头像，而非真实个人照片。

统计背景进一步裁去底部多余白色区域（原326px画布保留顶部256px，左右各裁60px），仍保留曲线边缘；统计文字恢复居中，调整统计卡与财务卡的间距。金额以小号货币符号和深色中等字重数字呈现，黄色强调线和比例条颜色贴近参考，比例分界增加细白斜线。项目的金额、登录时间和账单月份继续使用本地 Store，不复制截图中的私人财务值。

本轮参考结果截图：artifacts/abc-resources/verification/mine-real-reference.png。已检查权益文字单行、白字金底及轻阴影，通用男生头像、独立星级、黑金统计卡曲线、白底财务卡和收支比例分界。最终恢复默认首页入口，构建通过。金额/账单数据保持 Store 的值；未声明所有尺寸逐像素一致，参考与模拟器机型和状态栏不同。
