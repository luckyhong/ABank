# M9b 贷款待办、进度、结清证明与提前还款 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把我的贷款四个宫格入口、“历史贷款”和提前还款提交做成本地功能；提前还款成功才同时扣余额、减本金、记流水与办理记录。

**Architecture:** 方案 A：`LoanContract` 增加每期还款额/剩余期数/下期日期/期次，账本新增 `loanServiceRecords`；纯计算放 `LoanAmortization`/`LoanRules`，读写放新扩展 `FinanceLedgerStore+Loan.swift`，提前还款一次 `persist`。历史贷款与种子申请是只读目录。新页面与现有贷款页一样由导航直接 push，不新增 `AppRoute`。

**Tech Stack:** UIKit、SnapKit、Swift 5、iOS 15.6+；数据检查用 `xcrun swiftc` 编译运行。

**Spec:** `docs/superpowers/specs/2026-11-07-m9b-loan-design.md`

## Global Constraints

- 银行业务只用本地模拟数据；存储键仍为 `abank.financeLedger.record.v8`，新字段一律 `decodeIfPresent`，不重置历史。
- 新文件放在同步文件夹内，无需修改 pbxproj。
- 金额内部以分（`Int64`）计算，展示与 `LedgerTransaction`/`LoanContract` 字段用 `TransferMoney.amount`/`cents(from:)` 转换。
- 月利率 `r = annualRatePercent / 1200`；每期利息 = 本金分 × r，`Decimal` 四舍五入（`.plain`）到分。
- 提前还款金额：≥ 10000 分；最多两位小数（`TransferMoney.parse`）；≤ 借记卡余额；**<** 未还本金。
- 文案逐字使用 spec §3.4：`提前还款金额最低 100 元，最多两位小数`、`提前还款金额须小于未还本金`、`账户余额不足`、`贷款不存在或已结清`、`信息已变化，请重新确认`、`账本数据异常，暂不能办理`、`本地保存失败，请重试`、`请求无效，请重试`。
- 提前还款不检查 M9a 的 `AccountPermissions`。
- 新流水：标题 `提前还款-个人住房贷款`（`提前还款-` + 贷款名），`categoryId: "loan_repay"`，`iconKey: "house.fill"`，`direction: .expense`，`includeInFlow: true`，`transactionType: "贷款还款"`，`channel: "本机模拟"`。
- 付款账户显示一律用 `LedgerAccount.cardLabel`（`check_banking_data.sh` 的卡名守卫仍须通过）。
- 提交信息用中文 Conventional Commits；不推送、不合并。

## Review Focus

1. 已存旧账本（合同无新字段、无 `loanServiceRecords`）升级后照常显示，第 107 期数值不变——测试见 Task 1 `legacyDecode`、Task 2 `scheduleFromLedger`。
2. 确认弹窗期间余额或本金被其他页面改变（如另一处转账），再确认必须被拒且不扣款——测试见 Task 2 `changedWhileConfirming`。
3. 金额输入 `100.`、` 100 `、`1e3`、`０１００`（全角）等边界——`TransferMoney.parse` 已覆盖格式；本计划测试见 Task 1 `amountRules`。
4. 连点“确认”造成同一 `requestID` 两次提交只扣一次——测试见 Task 2 `idempotentReplay`；页面在提交期间禁用按钮（Task 3）。
